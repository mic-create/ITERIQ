# ITERIQ PDF Design Specification

## 1. Document Identity
- **Title**: ITERIQ | OFFICIAL ATTENDANCE REGISTER
- **Layout**: A4 Landscape
- **Aesthetic**: Premium academic register, typeset quality.

## 2. Color Palette
- **Primary Header**: Forest Green (`#1b4d3e`)
- **Page Background**: Warm Ivory (`#fcfbf9`)
- **Accent**: Restrained Bronze / Orange (`#c05621`)
- **Text & Borders**: Charcoal / Neutral Dark (`#2d3748`)

## 3. Structure & Layout
- **Header Section**: Institution name (Bells University of Technology), System brand (ITERIQ), Course Code, Course Title, Venue Name, Date, and Total Attendance Count.
- **Table Structure**: Serial Number (S/N), Student Full Name, Matriculation Number, Academic Level, Timestamp, and Verification Status. Multi-page pagination enabled via ReportLab flowables.
- **Footer Section**: Designated signature blocks for Course Representative and Assistant Course Representative.
